# A Direct Fourth-Order Causal-Set Operator: Curvature Corrections and Fluctuations
**Author:** Bishnu Gupta Teli

This repository contains the manuscript versions and computational notebooks accompanying the work on the construction and continuum-limit analysis of a direct fourth-order causal-set operator in arbitrary spacetime dimensions.

## Repository contents
| File | Description |
|---|---|
| **Interim manuscript (PDF)** | An earlier version of the manuscript, retained for reference and comparison. |
| **Current submitted manuscript (PDF)** | This is the definitive version to consult when referring to the present work. |
| **`code-operator.ipynb`** | Computational notebook for the tensor-algebra calculations underlying the continuum-limit analysis of the fourth-order operator. It contains the relevant tensor expansions, contractions, angular averages, and covariant reductions. |
| **`code-volume.ipynb`** | Computational notebook for the Alexandrov-interval volume expansion in Riemann normal coordinates. It contains the geometric expansions and integrations used in determining the volume contributions required for the continuum-limit calculation. |

## How to navigate the repository
For readers primarily interested in the results, begin with the **current submitted manuscript**.

For readers interested in the technical derivations and computational details, the recommended order is:
1. **`volume.ipynb`** — examine the calculation of the Alexandrov-interval volume and its expansion.
2. **`code-operator.ipynb`** — examine the tensor-algebra calculations used to obtain the continuum operator and its curvature corrections.

## Computational details
The notebooks provide the symbolic calculations supporting the analytical developments in the manuscript. They are intended to complement the derivations presented in the paper and to make the computational steps more transparent.

For consistency, the notebooks should be inspected and executed in their original cell order. The software environment and symbolic-algebra packages required for execution should be configured accordingly.
